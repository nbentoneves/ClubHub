# MVP Requirements

Replace the prompts below with your product requirements before asking an agent to implement them. Empty sections do not authorize features.

## Product and Users

What is the product, who uses it, and what problem does it solve?

## MVP Scope

List only the features required for the first usable version.

## User Flows

Describe each flow from the user's action to the expected outcome. Include relevant loading, empty, validation, and failure states.

## Data and Integrations

Describe data to persist, access rules, and any required external APIs. Specify authentication only if needed. Never include credentials here.

## Acceptance Criteria

Write concrete, testable outcomes for each required feature.

## Out of Scope

List anything explicitly excluded from this MVP.
